# Module 3 – Reports, Community and Audit

Owns `/report`, `/feed`, and `/dashboard`, plus the report/feed/checklist UI and accessibility score/alert components. Report validation, report handling, local report storage/event helper, and dashboard score summary are in `src/app/backend/module-3/`; `/api/reports` is the module's Next.js API entrypoint.

The current helper summarizes existing facility scores; the source does not yet calculate a separate four-factor compliance score.
