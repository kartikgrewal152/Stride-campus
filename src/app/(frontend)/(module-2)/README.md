# Module 2 – Campus Map and Facilities

Owns `/explore` and `/buildings/[slug]`, including the interactive map, 360 viewer used by the map page, route comparison card, and facility directory card. Campus graph/facility data, pathfinding, map API logic, and shared spatial utilities are in `src/app/backend/module-2/`. The `/api/buildings` and `/api/routes` Next.js entrypoints delegate their map logic here.
